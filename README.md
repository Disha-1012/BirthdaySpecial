
# 🎂 A Little Birthday Magic

An interactive birthday surprise website built with HTML, CSS, and
JavaScript. Created to make someone's special day even more memorable.

## ✨ Features

- Interactive envelope-opening animation.
- Birthday photo reveal and animated CSS cake.
- Floating clickable hearts, stars, gifts, and birthday decorations.
- Personal birthday letter with a photo.
- Interactive photo gallery popups with captions.
- Animated confetti and surprise birthday wishes.
- Responsive design for desktop, tablet, and mobile.
- No backend or paid API required.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## 🚀 Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Add your photos to `assets/images/`.
4. Open `index.html` in your browser, or use the Live Server
   extension in VS Code.

No package installation or build command is required.

## 🎨 Customization

- Change the main photo in `assets/images/hero.jpg`.
- Replace the three memory photos.
- Edit the birthday message in `index.html`.
- Customize photo captions in `script.js`.
- Modify colors, typography, and animations in `style.css`.

## 🌐 Deployment

This static website can be deployed on Vercel by importing the
GitHub repository and using the project root as the deployment root.

No build command or output directory is required.
